public class Main {

## Q07. Java — 생성자 내 오버라이딩 메서드 호출 (4점)

다음 Java 코드의 출력 결과를 쓰시오.

```java
class Parent {
    int x = 5;
    Parent() {
        x += show();   // show()는 동적 바인딩 → Child.show() 실행
    }
    int show() { return x; }
}

class Child extends Parent {
    int x = 100;
    Child() {
        x += 5;
    }
    @Override
    int show() { return x; }  // Parent 생성자에서 호출 시 Child.x=0(초기화 전)
}

public class Main {
    public static void main(String[] args) {
        Child c = new Child();
        System.out.println(c.x);          // Child.x 출력
        System.out.println(((Parent)c).x); // Parent.x 출력
    }
}
```

> 힌트: Child 생성 시 순서 — Parent 필드 초기화 → Parent() → Child 필드 초기화 → Child()  
> Parent() 실행 시 Child.x는 아직 초기화되지 않았으므로 0

## Q20. C언어 — 포인터 배열 역순 참조 (4점)
