### Q01 해설 — String Pool vs Heap
```
String Pool: 리터럴이나 컴파일 타임 상수는 Pool에 저장되고 재사용
Heap: new String() 또는 런타임 문자열 연산 결과는 별도 Heap 객체 생성

s1 = "world"          → Pool 저장
s2 = "wor" + "ld"     → 컴파일러가 "world"로 상수 접기(Constant Folding)
                         → Pool의 기존 "world"를 재사용 → s1과 같은 주소
s3 = new String("world") → 강제로 Heap에 새 객체 생성 (미사용)
tmp = "wor"           → Pool
s4 = tmp + "ld"       → tmp가 변수이므로 런타임 연산 → 새 Heap 객체

System.out.println(s1 == s2)      → Pool 주소 == Pool 주소 → true
System.out.println(s1.equals(s4)) → "world".equals("world") → true (내용 비교)

출력:
true
true
```

### Q05 해설 — 이진 트리 짝수 레벨 합계
```
배열 [1,2,3,4,5,6,7]로 표현된 완전 이진 트리

인덱스 i의 자식: 왼쪽=2i+1, 오른쪽=2i+2

레벨별 노드:
  레벨 0 (짝수): 인덱스 0 → [1]
```

### Q16 해설 — RIP vs OSPF 경로 선택
```
네트워크 구성 (간선의 숫자 = 링크 비용):
  A --1-- B
  A --4-- C
  B --1-- C
  B --5-- D
  C --2-- D

A → D 가능한 경로:
  ① A→B→D        : 홉=2, 비용=1+5=6
  ② A→C→D        : 홉=2, 비용=4+2=6
  ③ A→B→C→D      : 홉=3, 비용=1+1+2=4
  ④ A→C→B→D      : 홉=3, 비용=4+1+5=10

RIP (홉 수 최소):
  ①, ② 모두 2홉으로 동일 → 먼저 발견된 A→B→D 선택

OSPF (비용 합계 최소):
  ③ A→B→C→D = 4 → 최소

출력:
RIP:  A→B→D (2홉)
OSPF: A→B→C→D (비용 합계 4)
```
