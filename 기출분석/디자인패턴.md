# 디자인 패턴 단답형 문제

1. 구현부와 추상부를 분리하여 독립적으로 확장할 수 있도록 하는 패턴은?

2. 객체의 상태를 저장했다가 이전 상태로 복원하는 패턴은?

3. 원본 객체를 복제하여 객체를 생성하는 패턴은?

4. 기능을 동적으로 추가하기 위해 객체를 감싸는 방식의 패턴은?

5. 하나의 객체만 생성하여 공유하는 패턴은?

6. 요청을 처리할 수 있는 객체를 연결하여 순차적으로 전달하는 패턴은?

7. 여러 객체를 트리 구조로 구성하여 동일하게 다루는 패턴은?

8. 상태 변화가 발생하면 관련 객체들에게 자동으로 알리는 패턴은?

9. 서로 다른 알고리즘을 캡슐화하여 교체할 수 있는 패턴은?

10. 인터페이스가 맞지 않는 클래스를 사용할 수 있도록 변환하는 패턴은?

11. 상위 클래스에서 알고리즘의 골격을 정의하고 하위 클래스에서 세부 내용을 구현하는 패턴은?

12. 객체 생성을 서브 클래스에 위임하는 패턴은?

13. 관련 객체들을 그룹으로 생성하는 패턴은?

14. 인스턴스를 공유하여 메모리를 절약하는 패턴은?

15. 객체 간 복잡한 상호작용을 하나의 객체로 캡슐화하는 패턴은?

16. 자료 구조를 순차적으로 접근할 수 있도록 하는 패턴은?

17. 요청을 객체 형태로 캡슐화하는 패턴은?

18. 언어의 문법을 표현하는 패턴은?

19. 객체의 상태에 따라 동작이 달라지는 패턴은?

20. 데이터 구조와 처리 기능을 분리하는 패턴은?

21. 복잡한 서브 시스템을 하나의 인터페이스로 제공하는 패턴은?

22. 객체를 대리하여 접근을 제어하는 패턴은?

23. 작은 객체를 조합하여 큰 객체를 생성하는 패턴은?
