    str[right] = t;
    reverse(str, left + 1, right - 1);

### Q01 해설
```
A obj = new C()  →  선언 타입: A,  실제 타입: C

obj.get() → 동적 바인딩 → C의 get() 실행
  C.get() = super.get() + "+C:" + x
  super.get() = B.get() = "B:" + B.x = "B:B"
  "+C:" + C.x = "+C:C"
  → "B:B+C:C"

obj.x → 선언 타입(A) 기준 정적 바인딩 → A.x = "A"

출력:
B:B+C:C
A
```
