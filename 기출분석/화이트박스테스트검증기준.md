# 화이트박스 테스트 검증 기준

| 검증 기준 | 설명 | 특징 |
|-----------|------|------|
| **문장 검증 기준 (Statement Coverage)** | 소스 코드의 **모든 구문(Statement)** 이 **1회 이상 수행**되도록 테스트 케이스를 설계 | 가장 기본적인 커버리지 |
| **결정 검증 기준 (Decision Coverage)**<br>(= **분기 검증 기준, Branch Coverage**) | 모든 **조건문의 결과(True/False)** 가 각각 **1회 이상 수행**되도록 테스트 케이스를 설계 | 각 분기를 모두 수행 |
| **조건 검증 기준 (Condition Coverage)** | 조건문에 포함된 **개별 조건식**이 각각 **True와 False를 1회 이상** 수행하도록 테스트 케이스를 설계 | 개별 조건의 참/거짓 확인 |
| **조건/결정 검증 기준 (Condition/Decision Coverage)** | **결정 검증 기준 + 조건 검증 기준**을 모두 만족하도록 테스트 케이스를 설계 | 분기와 개별 조건을 모두 검증 |
| **변경 조건/결정 검증 기준 (MC/DC, Modified Condition/Decision Coverage)** | 각 **개별 조건식이 다른 조건의 영향 없이 독립적으로 전체 결과에 영향을 미치도록** 테스트 케이스를 설계 | 항공·국방 등 고신뢰성 시스템에서 많이 사용 |
| **다중 조건 검증 기준 (Multiple Condition Coverage)** | 조건문에 포함된 **모든 개별 조건식의 모든 조합(True/False)** 을 테스트하도록 설계 | 가장 강력하지만 테스트 케이스 수가 가장 많음 |

---

# 커버리지 강도(약 → 강)

```text
문장(Statement)
      ↓
결정(Decision = Branch)
      ↓
조건(Condition)
      ↓
조건/결정(Condition/Decision)
      ↓
변경 조건/결정(MC/DC)
      ↓
다중 조건(Multiple Condition)
```

---

# 암기 포인트

- **문장** → 모든 **구문** 실행
- **결정(분기)** → 모든 **True / False 분기** 실행
- **조건** → 모든 **개별 조건식 True / False** 실행
- **조건/결정** → **조건 + 분기** 모두 만족
- **MC/DC** → **각 조건이 독립적으로 결과에 영향**
- **다중 조건** → **모든 조건 조합** 검사
