# 결합도(Coupling)

> **결합도는 낮을수록 좋다.**
>
> **결합도 강함 ← 내용 > 공통 > 외부 > 제어 > 스탬프 > 자료 → 약함**

| 결합도 | 설명 | 특징 |
|--------|------|------|
| **내용 결합도 (Content Coupling)** | 한 모듈이 다른 모듈의 **내부 기능이나 내부 데이터를 직접 참조하거나 수정**하는 경우 | 가장 강한 결합도 |
| **공통(공유) 결합도 (Common Coupling)** | 여러 모듈이 **공통 데이터 영역(전역 변수)** 을 공유하는 경우 | 전역 변수 사용 |
| **외부 결합도 (External Coupling)** | 외부에서 선언한 데이터나 장치, 인터페이스 등을 여러 모듈이 참조하는 경우 | 외부 데이터 공유 |
| **제어 결합도 (Control Coupling)** | 다른 모듈의 처리 흐름을 제어하기 위해 **제어 신호(플래그 등)** 를 전달하는 경우 | 제어 정보 전달 |
| **스탬프(검인) 결합도 (Stamp Coupling)** | 배열, 레코드, 구조체 등 **자료구조 전체**를 전달하는 경우 | 필요한 데이터보다 큰 구조 전달 |
| **자료 결합도 (Data Coupling)** | 필요한 **자료(Data)만 매개변수로 전달**하는 경우 | 가장 이상적인 결합도 |

# 응집도(Cohesion)

> **응집도는 높을수록 좋다.**
>
> **응집도 강함 ← 기능 > 순차 > 교환(통신) > 절차 > 시간 > 논리 > 우연 → 약함**

| 응집도 | 설명 | 특징 |
|--------|------|------|
| **기능적 응집도 (Functional Cohesion)** | 모듈의 모든 기능이 **하나의 목적(기능)** 을 수행 | 가장 높은 응집도 |
| **순차적 응집도 (Sequential Cohesion)** | 앞 작업의 **출력이 다음 작업의 입력**이 되는 경우 | 데이터가 순차적으로 전달 |
| **교환(통신)적 응집도 (Communication Cohesion)** | 동일한 **입력 또는 출력 데이터**를 사용하는 기능들을 모아 놓은 경우 | 같은 데이터 사용 |
| **절차적 응집도 (Procedural Cohesion)** | 관련 기능들이 **정해진 순서**대로 수행되는 경우 | 수행 순서가 중요 |
| **시간적 응집도 (Temporal Cohesion)** | 특정 **시점에 함께 수행되는 기능**들을 모은 경우 | 초기화, 종료 처리 등 |
| **논리적 응집도 (Logical Cohesion)** | 유사한 성격의 기능들을 하나의 모듈로 구성한 경우 | 기능은 비슷하지만 목적은 다름 |
| **우연적 응집도 (Coincidental Cohesion)** | 서로 관련 없는 기능들을 우연히 하나의 모듈에 모아 놓은 경우 | 가장 낮은 응집도 |

# 암기법

## 결합도 (약 → 강)

```text
자 스 제 외 공 내

내용
↓
공통
↓
외부
↓
제어
↓
스탬프
↓
자료
```

> **"내공외제스자"**

---

## 응집도 (약 → 강)

```text
우 논 시 절 교 순 기

기능
↓
순차
↓
교환(통신)
↓
절차
↓
시간
↓
논리
↓
우연
```

> **"기순교절시논우"**

---

# 시험 포인트

- **결합도** : **낮을수록 좋다.**
- **응집도** : **높을수록 좋다.**
- **자료 결합도** ↔ 가장 약한 결합도(좋음)
- **내용 결합도** ↔ 가장 강한 결합도(나쁨)
- **기능적 응집도** ↔ 가장 높은 응집도(좋음)
- **우연적 응집도** ↔ 가장 낮은 응집도(나쁨)
