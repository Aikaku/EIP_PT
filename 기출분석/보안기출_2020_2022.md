# 보안 기출문제 정리 (2020~2022)

> 정보처리기사 실기 2020~2022년 기출문제 중 보안 관련 문항만 발췌·정리

---

## 2020년 1회

### Q07 — 해시 함수
> 다음 설명에 해당하는 알고리즘을 작성하시오.
> - 128비트의 해시값 출력
> - 무결성 검사에 사용
> - 입력 데이터의 무결성을 보장하기 위해 개발된 해시 알고리즘

**정답**: MD5

**핵심 포인트**
- MD5: 128비트 해시값, 무결성 검사용
- SHA-256(256비트) · SHA-512(512비트)와 구분
- MD5는 충돌 취약점으로 인해 현재 보안 용도로는 권장되지 않음

---

### Q10 — LAND Attack
> 다음 설명에 해당하는 공격을 작성하시오.
> - 패킷의 출발지 IP·포트를 목적지 IP·포트와 동일하게 위조
> - 공격 대상 서버가 자기 자신에게 응답을 무한 반복하여 자원을 소진

**정답**: LAND Attack

**핵심 포인트**
- 출발지 = 목적지 IP (IP 스푸핑의 변형)
- DoS 공격의 일종
- 대응: 방화벽에서 출발지·목적지 IP 동일 패킷 차단

---

## 2020년 2회

### Q08 — IPSec
> 다음 설명에 해당하는 보안 프로토콜을 영문 약자로 작성하시오.
> - IP 계층(3계층)에서 동작
> - 암호화, 인증, 키 관리 제공
> - 터널 모드 / 전송 모드 지원

**정답**: IPSec

**핵심 포인트**
- IP Security: 네트워크 계층 보안
- AH(Authentication Header): 인증·무결성
- ESP(Encapsulating Security Payload): 암호화·인증·무결성
- VPN 구현에 활용

---

### Q14 — SQL Injection
> 다음 설명에 해당하는 공격 기법을 작성하시오.
> - 입력 폼에 SQL 쿼리를 악의적으로 삽입
> - DB 인증 우회, 데이터 열람·조작 가능

**정답**: SQL Injection (SQL 삽입 공격)

**핵심 포인트**
- OWASP Top 10 대표 취약점
- 대응: PreparedStatement(파라미터 바인딩), 입력값 검증, 저장 프로시저
- 종류: Error-based, Blind, Union-based

## 2020년 4회

### Q07 — 스니핑
> 다음 설명에 해당하는 네트워크 공격을 작성하시오.
> - 네트워크 패킷을 도청하여 데이터(ID·PW 등)를 탈취
> - 비암호화 프로토콜(HTTP, FTP, Telnet)에서 특히 위험

**정답**: 스니핑 (Sniffing)

**핵심 포인트**
- 수동적(Passive) 공격: 데이터를 읽기만 하고 변조는 하지 않음
- 대응: 암호화 통신(HTTPS, SSH, SFTP) 사용
- 스위치 환경에서는 ARP 스푸핑과 결합하여 사용됨

---

### Q20 — 가용성 (CIA 3요소)
> CIA 3요소 중 "인가된 사용자가 필요할 때 정보에 접근할 수 있어야 한다"는 속성은?

**정답**: 가용성 (Availability)

**핵심 포인트**
| 요소 | 의미 |
|------|------|
| 기밀성(Confidentiality) | 인가된 사용자만 정보 접근 |
| 무결성(Integrity) | 정보가 변조되지 않음을 보장 |
| 가용성(Availability) | 인가된 사용자가 필요 시 정보 접근 가능 |

## 2021년 1회

### Q18 — DAC (임의적 접근 통제)
> 다음 설명에 해당하는 접근 통제 방식을 영문 약자로 작성하시오.
> - 데이터 소유자가 직접 접근 권한을 설정
> - 신분(Identity) 기반 접근 통제
> - 유닉스의 파일 권한(rwx) 방식

**정답**: DAC (Discretionary Access Control)

**핵심 포인트**
| 유형 | 기준 | 특징 |
|------|------|------|
| DAC | 소유자 재량 | Unix 파일 권한, 유연 |
| MAC | 보안 등급 | 군/정부, 엄격 |
| RBAC | 역할(Role) | 기업 환경, 관리 편리 |

---

### Q20 — 세션 하이재킹
> 다음 설명에 해당하는 공격을 작성하시오.
> - 공격자가 RST 패킷을 보내 TCP 연결을 강제 종료
> - 정상 세션 시퀀스 번호를 탈취하여 연결을 가로챔
> - 인증된 사용자의 세션을 훔쳐 통신 내용을 탈취·조작

**정답**: 세션 하이재킹 (Session Hijacking)

**핵심 포인트**
- TCP 세션의 시퀀스 번호 추측·탈취
- 대응: HTTPS(세션 암호화), 세션 타임아웃, 토큰 재발급
- 스니핑 → 시퀀스 번호 확인 → RST 전송 → 세션 탈취 순서

## 2021년 2회

### Q08 — AES
> 다음 설명에 해당하는 암호화 알고리즘을 작성하시오.
> - DES를 대체하기 위해 NIST가 표준화
> - 128비트 블록, 키 길이 128/192/256비트
> - 대칭키(비밀키) 알고리즘

**정답**: AES (Advanced Encryption Standard)

**핵심 포인트**
| 알고리즘 | 블록 크기 | 키 길이 | 비고 |
|----------|-----------|---------|------|
| DES | 64비트 | 56비트 | 구식, 취약 |
| 3DES | 64비트 | 112/168비트 | DES 3회 적용 |
| AES | 128비트 | 128/192/256비트 | 현재 표준 |

## 2021년 3회

### Q02 — AAA
> 다음 설명에 해당하는 보안 기술을 영문 약자로 작성하시오.
> - 인증(Authentication): 사용자 신원 확인
> - 인가(Authorization): 자원 접근 권한 부여
> - 계정관리(Accounting): 사용 이력 로깅

**정답**: AAA

**핵심 포인트**
- 네트워크 접근 통제의 핵심 프레임워크
- RADIUS, TACACS+ 프로토콜이 AAA 구현체
- 계정관리(Accounting)는 과금·감사로도 쓰임

---

### Q04 — ARP 스푸핑
> 다음 설명에 해당하는 공격을 작성하시오.
> - ARP 응답 패킷을 위조하여 피해자의 MAC 테이블을 오염
> - 공격자의 MAC 주소를 게이트웨이의 IP에 매핑
> - 스위치 환경에서 MITM(중간자 공격) 가능

**정답**: ARP 스푸핑 (ARP Spoofing)

**핵심 포인트**
- ARP는 IP → MAC 주소 변환 프로토콜
- ARP에는 인증이 없어 위조 응답이 그대로 수용됨
- 대응: 정적 ARP 설정, ARP 검사(DAI) 기능

---

### Q10 — DES
> 다음 설명에 해당하는 암호화 알고리즘을 작성하시오.
> - 64비트 블록 크기
> - 56비트 키 길이 (실질적으로 취약)
> - Feistel 구조, 16라운드

**정답**: DES (Data Encryption Standard)

**핵심 포인트**
- 56비트 키 → 브루트포스 공격에 취약 (현재 사용 금지 권고)
- 후계 알고리즘: 3DES → AES
- 대칭키(비밀키) 암호화

---

## 2022년 1회

### Q08 — TKIP
> 다음 설명에 해당하는 보안 프로토콜을 영문 약자로 작성하시오.
> - 임시 키 무결성 프로토콜
> - WEP의 취약점을 개선한 무선 랜 암호화 프로토콜
> - WPA에서 사용됨

**정답**: TKIP (Temporal Key Integrity Protocol)

**핵심 포인트**
- WEP → TKIP(WPA) → CCMP/AES(WPA2) 순으로 발전
- TKIP도 현재는 취약점 발견으로 WPA2(AES) 권장
- 무선 보안 프로토콜 진화 순서 암기

---

### Q16 — ISMS
> 다음 설명에 해당하는 용어를 영문 약자로 작성하시오.
> - 정보보호 관리체계
> - 조직의 정보자산을 보호하기 위한 체계적 관리 프레임워크
> - 국내: ISMS-P (개인정보보호 포함)

**정답**: ISMS (Information Security Management System)

**핵심 포인트**
- 국제 표준: ISO/IEC 27001
- 국내 인증: ISMS-P (ISMS + 개인정보보호)
- 기업 보안 정책·절차·통제 전반을 체계화

---

### Q18 — 워터링홀 (Watering Hole)
> 다음 설명에 해당하는 공격을 보기에서 고르시오.
> - APT 공격에 주로 사용
> - 공격 대상이 방문하는 합법적 웹사이트를 사전에 악성코드로 감염
> - 피해자가 해당 사이트 방문 시 자동으로 악성코드 설치

**정답**: Watering Hole (워터링홀)

**핵심 포인트**
- 표적 공격: 불특정 다수가 아닌 특정 그룹을 겨냥
- APT(Advanced Persistent Threat) 공격의 초기 침투 단계에서 사용
- 피싱과 차이: 피싱은 이메일로 유인, 워터링홀은 실제 웹사이트를 감염

## 2022년 2회

### Q02 — IDEA / Skipjack (대칭키 알고리즘)
> 다음 설명에 해당하는 대칭키 알고리즘을 보기에서 고르시오.

**정답**
1. **IDEA** (International Data Encryption Algorithm)
   - Xuejia Lai & James Massey 개발
   - 64비트 블록, 128비트 키, 8라운드

2. **Skipjack**
   - 미국 NSA 개발, Clipper 칩 탑재
   - 64비트 입출력, 80비트 키, 32라운드
   - 음성 암호화 용도

**핵심 포인트 — 주요 대칭키 알고리즘 비교**
| 알고리즘 | 블록 | 키 | 라운드 | 특징 |
|----------|------|-----|--------|------|
| DES | 64비트 | 56비트 | 16 | 취약, 구식 |
| 3DES | 64비트 | 112/168비트 | 48 | DES 3회 |
| AES | 128비트 | 128/192/256비트 | 10/12/14 | 현재 표준 |
| IDEA | 64비트 | 128비트 | 8 | 국제 표준 |
| Skipjack | 64비트 | 80비트 | 32 | NSA·Clipper |
| SEED | 128비트 | 128비트 | 16 | 국내(KISA) |
| ARIA | 128비트 | 128/192/256비트 | 12/14/16 | 국내(국정원) |

### Q05 — VPN
> 다음 설명에 해당하는 기술을 작성하시오.
> - 인터넷을 통해 디바이스 간 사설 네트워크 연결 생성
> - 데이터를 암호화하여 안전하게 전송
> - 사용자 IP 주소를 마스킹

**정답**: VPN (Virtual Private Network)

**핵심 포인트**
- 터널링 프로토콜: IPSec, SSL/TLS, L2TP, PPTP
- 원격 근무 환경에서 내부망 접근에 활용
- SSL VPN vs IPSec VPN: SSL은 브라우저 기반, IPSec은 OS 계층

## 2022년 3회

### Q08 — 사회공학적 기법 / 다크 데이터
> 다음 설명에 해당하는 답을 작성하시오.

**정답**
1. **사회공학 (Social Engineering)**
   - 기술적 방법이 아닌 사람 간의 신뢰를 이용하여 비밀 정보 획득
   - 기법: 피싱, 비싱(전화), 스미싱(SMS), 사칭

2. **다크 데이터 (Dark Data)**
   - 수집·저장 후 분석하지 않는 비활용 데이터
   - 저장 공간만 차지하며 보안 위험 초래 가능

**핵심 포인트**
- 사회공학 대응: 보안 교육, 전화/이메일 신원 확인 절차
- 다크 데이터 위험: 개인정보 포함 가능 → 데이터 거버넌스 필요

---

### Q10 — SIEM
> 다음 설명에 해당하는 보안 솔루션을 작성하시오.
> - 머신러닝으로 대량의 IT 로그를 통합 관리·분석
> - 이기종 보안 솔루션 로그를 중앙에 수집
> - 이상징후 탐지 및 사전 위협 대응

**정답**: SIEM (Security Information and Event Management)

**핵심 포인트**
- SIM(보안 정보 관리) + SEM(보안 이벤트 관리) 통합
- 네트워크·서버·보안 장비 로그를 한 곳에서 분석
- 관련 기술: ESM(통합보안관제), SOC(보안운영센터)

---

### Q14 — TrustZone / 타이포스쿼팅
> 다음 설명에 해당하는 답을 보기에서 고르시오.

**정답**
1. **TrustZone**
   - ARM이 개발한 하드웨어 기반 보안 기술
   - 프로세서 내 독립적인 보안 구역(Secure World) 분리
   - 중요 정보(키, 생체인증 데이터 등)를 일반 OS와 격리

2. **타이포스쿼팅 (Typosquatting)**
   - 유명 도메인의 오타·유사 도메인을 미리 등록
   - URL 하이재킹(URL Hijacking)이라고도 함
   - 예: `gooogle.com`, `paypa1.com`

**핵심 포인트**
- TrustZone: 모바일 보안의 핵심 (TEE, Trusted Execution Environment)
- 타이포스쿼팅 대응: 주소 입력 시 확인, 북마크 사용

---

### Q15 — SSO
> 다음 설명에 해당하는 용어를 작성하시오.
> - 한 번의 로그인으로 여러 사이트/서비스에 자동 접속
> - 통합 인증 관리

**정답**: SSO (Single Sign-On)

**핵심 포인트**
- 장점: 사용자 편의성 향상, 패스워드 관리 부담 감소
- 단점: SSO 계정이 탈취되면 모든 연동 서비스 피해
- 구현 기술: SAML, OAuth 2.0, OpenID Connect

## 분류별 빈출 키워드

### 암호화 알고리즘 (자주 출제)
- **대칭키**: DES(56비트), 3DES, AES(128비트 블록), SEED(국내), ARIA(국내), IDEA, Skipjack, TKIP
- **해시**: MD5(128비트), SHA-1(160비트), SHA-256(256비트)
- **비대칭키(공개키)**: RSA, ECC, DSA

### 네트워크 공격
- **스푸핑 계열**: ARP 스푸핑, IP 스푸핑, DNS 스푸핑
- **스니핑**: 패킷 도청
- **DoS/DDoS**: LAND Attack, SYN Flooding, Smurf
- **세션 탈취**: 세션 하이재킹

### 접근 통제
- DAC(소유자 재량) / MAC(보안 등급) / RBAC(역할 기반)
- AAA: 인증(Authentication) / 인가(Authorization) / 계정(Accounting)

### 보안 솔루션/관리
- ISMS: 정보보호 관리체계
- SIEM: 로그 통합 분석
- SSO: 단일 로그인
- VPN: 가상 사설망 (IPSec, SSL)

### 웹/사이버 공격
- SQL Injection, XSS, CSRF
- 워터링홀, 타이포스쿼팅
- 사회공학(Social Engineering)
