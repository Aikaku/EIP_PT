**Q09.** 다음 두 테이블을 참고하여 SQL 실행 결과를 작성하시오.

주문 테이블

| 주문번호 | 고객번호 | 금액   |
|---------|---------|--------|
| 001     | C01     | 50000  |
| 002     | C02     | 30000  |
| 003     | C01     | 80000  |
| 004     | C03     | 20000  |
| 005     | C02     | 60000  |

고객 테이블

| 고객번호 | 이름   |
|---------|--------|
| C01     | 김철수 |
| C02     | 이영희 |
| C03     | 박민준 |

```sql
SELECT 고객.이름, SUM(주문.금액) AS 총금액
FROM 고객
INNER JOIN 주문 ON 고객.고객번호 = 주문.고객번호
GROUP BY 고객.고객번호, 고객.이름
HAVING SUM(주문.금액) >= 80000
ORDER BY 총금액 DESC;
```

## 코드 문제 풀이 해설

### Q01 해설
```
try 블록: "try " 출력 후 return 1 시도
→ return 실행 전에 finally가 먼저 실행됨
finally 블록: "finally " 출력 후 return 2
→ finally의 return이 try의 return을 덮어씀

최종 반환값: 2
출력: try finally 2
```

### Q02 해설
```
n=3 → case 3부터 실행
case 3: result += 3 → result = 3
case 4: result += 4 → result = 7 (break 실행)
case 5: 실행 안 됨

출력: 7
```

### Q03 해설
```
a=5, b=10
*p = a, *q = b

*p += *q  →  a = a + b = 5 + 10 = 15
*q = *p * 2  →  b = 15 * 2 = 30

*p + *q = 15 + 30 = 45

출력: 15 30 / 45
```

### Q05 해설

```
p[0][2]         = a[0][2] = 3
(*(p+1))[1]     = a[1][1] = 6
**p + p[1][3]   = a[0][0] + a[1][3] = 1 + 8 = 9

출력: 3 / 6 / 9
```
