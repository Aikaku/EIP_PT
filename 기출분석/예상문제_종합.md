**Q09.** 다음 테이블을 참고하여 SQL 실행 결과를 작성하시오.

성적 테이블

| 이름   | 과목 | 점수 |
|--------|------|------|
| 홍길동 | 수학 | 90   |
| 홍길동 | 영어 | 80   |
| 이순신 | 수학 | 70   |
| 이순신 | 영어 | 85   |
| 강감찬 | 수학 | 95   |
| 강감찬 | 영어 | 65   |

```sql
SELECT 이름, AVG(점수) AS 평균점수
FROM 성적
GROUP BY 이름
HAVING AVG(점수) >= 80
ORDER BY 평균점수 DESC;
```

## 코드 문제 풀이 해설

### Q01 해설
```
A obj = new B()  →  선언 타입: A,  실제 타입: B

obj.print()  →  동적 바인딩 → B의 print() 실행
               B의 print() 안에서 x는 B.x = 2
               → "B2" 출력

obj.x        →  선언 타입(A) 기준 정적 바인딩 → A.x = 1
               → "1" 출력

최종 출력: B21
```

### Q02 해설
```
new Child() 호출
  → Child() 진입
  → super(3) : Parent(int n) 호출 → "P3" 출력
  → "C" 출력

최종 출력: P3C
```

### Q03 해설
```
p = "HELLO" (H=72)

p + 2       →  인덱스 2부터 끝까지 → "LLO"
*(p + 1)    →  인덱스 1의 문자 → 'E'
*p + 1      →  'H'의 ASCII(72) + 1 = 73 = 'I'

출력:
LLO
E
I
```

### Q04 해설
```
f(5) = f(4) + 5
f(4) = f(3) + 4
f(3) = f(2) + 3
f(2) = f(1) + 2
f(1) = f(0) + 1
f(0) = 0

→ 0 + 1 + 2 + 3 + 4 + 5 = 15
```

### Q09 해설
```
GROUP BY 이름 후 AVG 계산:
  홍길동: (90+80)/2 = 85.0  → HAVING 충족 ✓
  이순신: (70+85)/2 = 77.5  → HAVING 미충족 ✗
  강감찬: (95+65)/2 = 80.0  → HAVING 충족 ✓

ORDER BY 평균점수 DESC:
  홍길동 | 85.0
  강감찬 | 80.0
```
