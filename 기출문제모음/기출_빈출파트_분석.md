## 공부 우선순위 추천

```
1주차: C코드 집중 (포인터·구조체·재귀·static·연결리스트)
         Java코드 집중 (다형성·오버라이딩·예외처리·String)

2주차: SQL 전 유형 (SELECT·JOIN·서브쿼리·DDL·DML·집계함수)
         소프트웨어 테스트 (커버리지 5종 + 동치분할 + 스텁/드라이버)

3주차: 네트워크 (OSPF/RIP/HDLC/ATM/BGP)
         Python코드 (슬라이싱·set·split)
         보안 공격 (웜/바이러스/트로이목마 + APT + XSS/SQLi)

4주차: 디자인 패턴 (GoF 23개 분류 암기 + Singleton/Proxy/Iterator 상세)
         DB 이론 (릴레이션·정규화·트랜잭션·키·무결성)
         결합도/응집도 + 암호화 + UML
```

> **핵심**: 코드 3언어 + SQL + 소프트웨어테스트 = 전체의 **49%**  
> 이 5파트만 잡으면 60점 확보 가능
